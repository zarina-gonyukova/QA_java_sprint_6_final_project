# qa_java – проект по юнит‑тестированию

Учебный Java‑проект, в котором реализована небольшая модель зоопарка и полный набор юнит‑тестов с покрытием 100% по основным классам. Проект использует JUnit 4, Mockito, JaCoCo и Maven.

## Технологии

- Java 11
- Maven
- JUnit 4.13.2
- Mockito 3.12.4
- JaCoCo 0.8.7

## Структура

Исходный код: `src/main/java/com/example`  
Тесты: `src/test/java/com/example`

### Основные классы

- `Animal` – базовый класс, описывает семейство и количество детёнышей.
- `Predator` – интерфейс для хищников с методом `getMeatMenu()`.
- `Feline` – кошачьи: наследует `Animal`, реализует `Predator`, возвращает меню, вид (`Felis catus` / `Panthera leo`) и полную классификацию.
- `Cat` – кот, использует `Feline` через композицию, делегирует семейство и котят.
- `Lion` – лев, получает `Feline` через конструктор, валидирует пол, определяет наличие гривы и рацион.
- `Alex` – конкретный лев Алекс из мультфильма: друзья, зоопарк, профиль, проверка места проживания.

### Тесты

- `AnimalTest` – проверки базового поведения `Animal`.
- `FelineTest` – семейство, котята, мясное меню, тип и классификация.
- `FelineParameterizedTest` – параметризованные тесты зависимости типа (`wild/domestic/...`) и видового имени.
- `CatTest` – звук, делегирование к `Feline`, имя и текстовое описание кота.
- `LionTest` – грива, валидация пола, делегирование еды, нормализация пола, описание льва.
- `LionMockTest` – пример использования Mockito для делегирования `getKittens()` в `Feline`.
- `AlexTest` – котята, друзья, зоопарк, еда через мок `Feline`, профиль и методы `livesInZoo()`.

## Запуск тестов

Требования: установлен JDK 11+ и Maven.

```bash
mvn test
```

В результате Maven:

- собирает проект;
- запускает все JUnit‑тесты;
- создаёт HTML‑отчёт JaCoCo в `target/site/jacoco/index.html`.

## Покрытие JaCoCo

После `mvn test` открой:

```text
target/site/jacoco/index.html
```

Отчёт показывает покрытие по каждому классу. Для классов `Animal`, `Feline`, `Cat`, `Lion`, `Alex` покрытие тестами составляет 100% по инструкциям и методам.

## Цель проекта

Проект используется как тренажёр для:

- практики юнит‑тестирования на Java (JUnit 4);
- работы с Mockito (моки и изоляция зависимостей);
- повышения покрытия кода и чтения отчётов JaCoCo;
- отработки практики работы с Maven и структурой Java‑проекта.
